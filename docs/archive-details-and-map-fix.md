# Archive details, photographs and inline controls — 30 September 2026

Archive information is now incorporated into the narrative of 20 property accounts with inline source references. All 42 existing archive references have contextual paragraphs. Digitised pages actually inspected are distinguished from catalogue descriptions and secondary transcripts; unseen documents are not presented as read. The collection contains 53 accounts, 306 source entries and 18 displayed images.

New licensed views show the Lockinge Orangery and associated estate buildings (Des Blenkinsopp, CC BY-SA 2.0), and Lillesden before restoration in 2010 (dxa5on / restlessglobetrotter, CC BY 2.0). Captions distinguish surviving estate buildings from demolished houses and historic condition from current condition. Property images precede portraits in galleries. Unverified or unlicensed images have not been invented or embedded.

The reviewed publication created 21 append-only research revisions in both verification and live databases. Source references, existing edits and property history remain available.

Map tile images now use the canonical OpenStreetMap endpoint with an origin-only cross-site referrer. This corrects the global same-origin referrer policy's suppression for map requests while preserving that policy elsewhere. Tile errors display an accessible notice; pins and the location list remain usable. Local browser checks confirmed loaded tiles on desktop and mobile.

Person selection now opens an inline textbox and results within its component, without a modal or body portal. Search supports names and original numbers, identity details, arrow keys, Enter, Escape and touch selection.
